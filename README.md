## 🚀 Featured Projects

### 🤖 Saudi Labor Law Assistant — Arabic RAG
An Arabic chat assistant that answers Saudi Labor Law questions — including questions in Saudi dialect — and cites the exact legal articles it relied on.
- Article-level chunking of the official law (214 active articles)
- Fusion retrieval: original + LLM-rewritten queries merged with Reciprocal Rank Fusion
- **92% retrieval accuracy (Hit@6)** on a human-reviewed Saudi-dialect test set
- Grounded answers only — says so when the law doesn't cover a question

**▶️ [Try it live](https://saudi-labor-law-assistant.streamlit.app/)** · [Code](https://github.com/fhdalmghamsy/arabic-labor-law-rag)

`Python` `ChromaDB` `Multilingual Embeddings` `Gemini API` `Streamlit`

### 🏠 Saudi Real Estate Price Predictor — Machine Learning
A web app that estimates price per m² and total price for any property from its city, neighborhood, area, and type — trained on real Ministry of Justice transactions.
- Cleaned 34,664 transactions, removing ~10% invalid deals (impossible areas, share sales, extreme prices)
- Target encoding for 4,000+ neighborhoods; log-transformed target
- Random Forest model: **R² ≈ 0.70, MAE ≈ 578 SAR/m²**, chosen over XGBoost variants
- Interactive Streamlit app with city-filtered neighborhood selection

**▶️ [Try it live](https://saudi-real-estate-predictor.streamlit.app/)** · [Code](https://github.com/fhdalmghamsy/saudi-real-estate-price-predictor)

`Python` `scikit-learn` `Random Forest` `Streamlit`
